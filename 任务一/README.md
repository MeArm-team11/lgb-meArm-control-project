# 任务一说明

# 硬件信息

- base：D9
- fArm：D8
- rArm：D6
- claw：D7
- 串口波特率：9600
- 摇杆输入：A0、A1、A2、A3

# 任务一分任务
00-总任务：最终合并程序。
01-基础控制：摇杆独立控制四个舵机。
02-固定串口指令：O/S/H/L 指令。
03-多舵机协同：x,y,z 单行指令。
04-GitHub版本管理：提交记录和分支建议。

00-总程序同时支持摇杆控制、固定指令 `O/S/H/L/R`、单关节指令 `b90/f60/r100/c30` 和协同指令 `x10,y30,z20`。

角度范围沿用调试代码：底座 `0~180`，前臂 `15~120`，后臂 `40~170`，夹爪 `5~90`，初始角度为 `90`。
