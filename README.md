## 二、快速开始

1. 用 Arduino IDE 打开对应任务的 `.ino`（任务五需连同同目录 `types.h`），按实际板型选择开发板与端口。
2. 机械臂板烧录任务代码，硬件串口波特率 **9600**。
3. 按键板程序 `button_panel/button_panel.ino` 单独烧录到控制板，USB 调试口波特率 **115200**。
   该程序需要 **Adafruit SSD1306** 库（在库管理器中安装时会自动带上 Adafruit GFX）。
   烧录前若不确定 OLED 的 I2C 地址，可先烧 `button_panel/i2c_scan/i2c_scan.ino` 扫描地址。
4. 打开机械臂端串口监视器，发送单字符指令（**不带回车换行**）或角度指令（`x,y,z` 形式**需要回车或换行**结束）。

> 注意：单字符指令在字符到达时立即执行；若串口监视器自动补发换行，会额外触发一次空行解析并打印"指令格式错误"。发送单字符时请关闭行尾符。

## 三、硬件与引脚

### 3.1 机械臂端（Arduino Uno）

| 用途 | 引脚 |
|---|---|
| 底座舵机 b | D9 |
| 前臂舵机 f | D8 |
| 后臂舵机 r | D6 |
| 夹爪舵机 c | D7 |
| 底座摇杆 | A0 |
| 后臂摇杆 | A1 |
| 夹爪摇杆 | A2 |
| 前臂摇杆 | A3 |
| 上位机串口 | USB，9600 8N1 |

角度范围（任务五工程内已按实测放宽，任务一文档记录的是调试期的保守值）：

| 关节 | 任务一记录 | 任务五工程当前值 |
|---|---|---|
| 底座 b | 0 ~ 180 | 0 ~ 180 |
| 前臂 f | 15 ~ 120 | 0 ~ 150 |
| 后臂 r | 40 ~ 170 | 0 ~ 180 |
| 夹爪 c | 5 ~ 90 | 5 ~ 110 |

上电初始姿态：`b90 / f90 / r90`，夹爪按 `cMax` 闭合。

### 3.2 按键控制板（Arduino Uno R3 + IIC OLED，8 键）

按键一端接引脚、一端接 GND，使用芯片内部上拉，按下读到 LOW，无需外接电阻。

| 按键 | 引脚 | 发送字符 | 功能 |
|---|---|---|---|
| 按键1 | D4 | `N` | 循环执行 A/B/C 夹取放置 |
| 按键2 | D5 | `R` | 开始 / 停止录制 |
| 按键3 | D6 | `T` | 回放上次录制的动作 |
| 按键4 | D7 | `M` | 回到初始姿态 |
| 按键5 | D8 | `F` | 绘图模式切换（LINE / LETTER / 5PT POLY / 5PT CURVE） |
| 按键6 | D9 | `D` | 开始 / 暂停 / 继续 |
| 按键7 | D10 | `I` | 记录当前示教点（满 5 点后再按 = 清空重记） |
| 按键8 | D11 | `Q` | 取消并回中（示教点保留） |

| 项目 | 说明 |
|---|---|
| OLED | IIC，SDA = A4，SCL = A5，地址 0x3C（少数模块为 0x3D） |
| 与机械臂通信 | 软串口 TX = D3，9600 8N1，只发单字符，不加回车换行 |
| 调试口 | 硬件串口 D0/D1，115200 |
| 去抖时间 | 30 ms（计时确认法） |

通信接线：本板 D3(TX) → 机械臂 D12(RX)，两板必须 **共地**。两端都是 Uno、都是 5V，直接连接，不需要分压。

> 两块板烧录都不需要拔线：机械臂的硬件串口 D0/D1 专供电脑，按键板走另一路软串口。

## 四、串口指令协议（任务五合并工程 `armDataCmd()`）

### 4.1 单字符指令（立即执行）

| 指令 | 功能 |
|---|---|
| `O` | 打开夹爪 |
| `S` | 关闭夹爪 |
| `H` | 提高运行速度（减小 DSD，有下限） |
| `L` | 降低运行速度（增大 DSD，有上限） |
| `P` | 打印当前四关节角度状态 |
| `A` / `B` / `C` | 执行对应物体的夹取—移动—放置动作 |
| `N` | 循环切换 A → B → C → A（按键1 使用） |
| `R` | 第一次按下开始录制，再次按下停止并保存（按键2 使用） |
| `T` | 回到录制起点并完整回放（按键3 使用） |
| `M` | 按预设顺序回到初始姿态（按键4 使用） |
| `K` | 正逆运动学往返自检 |
| `V` | 舵机映射校验（当前角度换算成坐标） |

以下四个字符由按键板的按键5~8 发送，机械臂端的对应分支尚未加入，按下去暂时没有反应：

| 指令 | 计划功能 |
|---|---|
| `F` | 绘图模式循环切换 |
| `D` | 开始 / 暂停 / 继续 |
| `I` | 记录示教点 |
| `Q` | 取消并回中 |

### 4.2 角度指令（需回车或换行结束）

| 形式 | 说明 |
|---|---|
| `x120,y60,z100` | 同时设置 x=底座、y=前臂、z=后臂的目标角度，三关节协同到位 |
| `b90` / `f60` / `r100` / `c30` | 单关节角度设置 |

超出安全范围的角度会被限制到范围内。

### 4.3 录制参数

采样间隔 200 ms，最多 80 帧（约 16 s），存满自动停止。数据保存在内存中，掉电丢失，重新录制会覆盖旧记录；录制期间禁止播放，少于两帧不播放。

## 五、运动学与舵机映射

任务五工程内已实现任务四推导的正解与逆解，并用 `K` 指令做往返自检（正解 → 逆解 → 对比，实测三组误差均为 0）。

运动学参数（取任务四文档名义值，单位毫米，实测校正后需替换）：

| 参数 | 含义 | 名义值 |
|---|---|---|
| L1 | 大臂轴心距 | 80 |
| L2 | 小臂轴心距 | 80 |
| L3a | 底座回转轴 → 肩轴 水平距离 | 60 |
| L3b | 腕轴 → 夹持参考点 水平距离 | 15 |
| h | 肩轴相对安装面高度 | 65（已实测核对） |

舵机指令与数学角度的换算关系（实测标定）：

```
alpha = 180 - f      大臂倾角，f=90 时大臂竖直向上
beta  = 90  - r      小臂相对角，r=90 时小臂水平
theta = b   - 90     底座回转角，b=90 时指向 +X
```
