# meArm 机械臂控制工程

十二期二面（控制方向）个人项目，作者：刘广博 / 3126002944 / 给排水。

工程包含基础舵机控制、自动取放、动作录制回放、正逆运动学以及示教绘图。任务一至三保留独立示例，任务五是集成运行程序；机械臂和八键控制板分别使用 Arduino Uno。

**2026-10-16 更新：任务五使用 XYZ 轨迹插值与逆运动学驱动多舵机，支持固定直线、固定三角形、五点直线和五点曲线，并增加锁高示教及记录前检查。**

## 编译与接线

1. 安装 Arduino IDE 及 Arduino AVR Boards，开发板选择 **Arduino Uno**；机械臂程序使用 `Servo` 和 `SoftwareSerial`，缺少时安装相应库。
2. 打开 `任务五/task5_drawing/task5_drawing.ino`，确保 `types.h` 在同一目录，再编译、上传到机械臂板。
3. 若使用实体按键，将 `ArduinoUnoR3_IIC_OLED/ArduinoUnoR3_IIC_OLED/ArduinoUnoR3_IIC_OLED.ino` 单独上传到按键板。
4. 按键板 D3（软串口TX）接机械臂板 D12（软串口RX），两板共地。板间通信 **9600**；机械臂USB串口 **9600**，按键板USB调试串口 **115200**。
5. 机械臂上电初始指令为 `b=f=r=90`、夹爪 `c=130`。正式落笔前先核对装配、限位和纸面位置；程序没有自动探测纸面。

| 机械臂功能 | 引脚 |
|---|---|
| 底座 / 前臂 / 后臂 / 夹爪舵机 | D9 / D8 / D6 / D7 |
| 底座 / 前臂 / 后臂 / 夹爪摇杆 | A0 / A3 / A1 / A2 |
| 按键板接收 / 预留发送 | D12 / D13 |

当前集成程序中，底座、前臂和后臂配置限位均为 **10～170°**，夹爪为 **5～130°**。这些是本机程序配置，不是所有 meArm 的通用标定值。

## 任务五模式与操作

`F` 按以下顺序循环模式，默认直线。固定图形尺寸在程序常量中设置。

| 模式 | 输入与路径 |
|---|---|
| 直线 | 无需示教；当前纸面位置起笔，沿底座朝向向外画30mm直线 |
| 三角形 | 无需示教；当前位置起笔，画边长30mm等边三角形；第2/3顶点各停至少300ms，末边经过起点后延长25%（7.5mm），延长终点停600ms再抬笔 |
| 五点直线 | 记录恰好5点，依次1→2→3→4→5，首尾不连接 |
| 五点曲线 | 记录恰好5点，使用Catmull–Rom插值平滑经过各点，首尾不连接 |

固定图形：先将笔尖轻触纸面，再按 `D`。绘制结束会抬笔，再次开始前需重新放回期望的纸面起点。固定图形不覆盖保存的五点示教数据。

五点模式推荐流程：

1. `F` 选择五点直线或五点曲线。如需重新示教，在空闲时发 `E` 清空任务五示教点，机械臂保持原位。
2. 用原摇杆将笔尖轻触纸面，松杆后按 `I` 记录第1点；看到“已记录”才表示成功。
3. 保持首点姿态，串口发送 `J`，确认“锁高示教已开”，再让所有摇杆回中。
4. 原底座轴控制平面Y，原前臂轴控制平面X，程序联动三个舵机保持首点的**模型Z**；后臂和夹爪摇杆暂时忽略。
5. 每到一个点松开平面摇杆并按 `I`，记满5点后 `D` 执行。再次 `J` 可退出锁高；开始绘图会自动退出。

不发 `J` 时仍可使用原独立关节摇杆示教。记录时保留原始角度，检查原始姿态、相对首点不超过5mm的高度差及统一高度后的可达性；失败不占点号，调整后再 `I`。锁高点额外保存未取整的目标坐标，减少坐标累积漂移。`D` 仍检查整条绘图与接近/收笔路径。

锁高只约束数学模型，不是接触检测。示教定位不自动抬笔，贴纸移动可能留下笔迹。若实物压纸或悬笔，应停止并检查标定，不能通过取消限位解决。

## 指令与实体按键

| 指令 | 功能 | 实体按键 |
|---|---|---|
| `N` | 依次执行A/B/C取放 | 1，D4 |
| `R` | 开始/停止录制 | 2，D5 |
| `T` | 回放 | 3，D6 |
| `M` | 普通状态回中；绘图异常锁定时解除锁定并保持原位 | 4，D7 |
| `F` | 循环绘图模式 | 5，D8 |
| `D` | 开始/暂停/继续绘图 | 6，D9 |
| `I` | 五点模式记录当前点；固定图形不需要记点 | 7，D10 |
| `Q` | 绘图时尝试抬笔取消并回中；空闲时回中 | 8，D11 |
| `J` / `E` | 开关锁高示教 / 清空五点示教 | 电脑串口 |
| `U` | 继续暂停的绘图 | 电脑串口 |
| `H` / `L` | 加快 / 放慢，调整每度等待时间DSD | 电脑串口 |
| `P` | 打印舵机指令角 | 电脑串口 |
| `O` / `S` | 张开 / 关闭夹爪 | 电脑串口 |
| `A` / `B` / `C` | 执行对应组取放 | 电脑串口 |
| `1`～`6` | 记录A取/A放/B取/B放/C取/C放姿态 | 电脑串口 |
| `K` | 正逆运动学往返自检 | 电脑串口 |

按键使用内部上拉，一端接对应引脚，一端接GND。单字符命令立即解析，当前机械臂版本忽略空的回车/换行。角度命令如 `x90,y113,z30` 必须以回车或换行结束；此处x/y/z表示底座/前臂/后臂**角度**，不是笛卡尔坐标。

绘图期间接受 `D/Q/U/P/H/L`，其他运动命令被拒绝；异常轨迹不能强行恢复，使用 `Q` 尝试抬笔退出，若失败则 `M` 解除锁定后人工处理。示教和录制数据存于RAM，复位或断电后丢失。

## 实现与验证

任务五采用“舵机角→正运动学→XYZ插值→逆运动学→三舵机更新”。绘图约每1mm采样，最小采样间隔35ms，同时根据最大关节角差与DSD延长间隔；没有严格恒定末端速度或完整加减速曲线。整条接近、落笔、绘制和收笔路径先预检，抬笔高度从10mm到2mm逐级选择可行值；保留限位、奇异边界余量与每步最大3度变化检查。

任务一至三的主要控制函数、任务二取放升降步骤保持原实现；共用串口入口增加任务五互斥，并修复角度命令中的数字被误识别为标定键的问题。任务四主体公式保留，逆解增加非有限值、回转轴及退化距离检查；任务五使用实测姿态修正角度映射和有效径向偏移。

2026-10-16 对当前任务五源文件重新验证：

- Arduino Uno编译通过：程序30,596/32,256字节，全局RAM 1,254/2,048字节；剩余794字节不是实测最大栈余量。
- 本地主机测试通过13,484项检查，包含1,647组运动学映射。
- 原版与修改版任务一至三各通过2,728项回归检查，测试轨迹哈希一致。

测试脚本和测试基线目前保存在开发机仓库外的工作目录，不包含在本次仓库交付中；上述为本地验证记录，仓库尚未配置自动CI。这些结果不等于完整实机精度认证。

当前尺寸/零位及笔尖偏移仍需按实际装配核对；有效径向修正 `-8.99mm` 是根据本机测量得到的初步补偿。整数舵机角、回差和笔尖弹性可能造成误差。三角形末边延长会在理想起点外多出一段线，属于可调笔迹补偿，不是精确几何校准；设 `triangleLastEdgeExtraRatio=0` 可关闭。

“统一高度后不可达”可能由模型误差与限位边界共同导致，程序会报告越界关节要求的角度和配置范围。每个点能到不代表点间直线或曲线及抬笔都能到；请根据具体错误调整示教位置或校准模型。
