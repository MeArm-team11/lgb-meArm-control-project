## 二、快速开始

1. 用 Arduino IDE 打开对应任务的 `.ino`（任务五需连同同目录 `types.h`），按实际板型选择开发板与端口。
2. 机械臂板烧录任务代码，硬件串口波特率 **9600**。
3. 按键板程序 `ArduinoUnoR3_IIC_OLED/ArduinoUnoR3_IIC_OLED/ArduinoUnoR3_IIC_OLED.ino` 单独烧录到控制板，USB 调试口波特率 **115200**，与机械臂通信的软串口波特率 **9600**。
   当前按键板不使用屏幕，不需要 Adafruit SSD1306 或 Adafruit GFX；`I2C_test` 保留用于单独排查 OLED 地址，不参与正式按键控制。
4. 机械臂程序使用 `Servo`、`SoftwareSerial`，按键板使用 `SoftwareSerial`；选择 Arduino Uno，缺少相应库时先安装。
5. 打开机械臂端串口监视器，发送单字符指令或角度指令（`x,y,z` 形式**需要回车或换行**结束）。

> 单字符指令在字符到达时立即执行，当前任务五程序会忽略空的回车或换行。固定图形需先将笔尖轻放纸面再按 D；五点模式的示教步骤见 4.4。

## 三、硬件与引脚

### 3.1 机械臂端（Arduino Uno）

| 用途 | 引脚 |
|---|---|
| 底座舵机 b | D9 |
| 前臂舵机 f | D8 |
| 后臂舵机 r | D6 |
| 夹爪舵机 c | D7 |
| 底座摇杆 | A0 |
| 后臂摇杆 | A1 |
| 夹爪摇杆 | A2 |
| 前臂摇杆 | A3 |
| 上位机串口 | USB，9600 8N1 |

角度范围（以下为当前任务五合并工程配置，独立任务及早期调试程序可能不同）：

| 关节 | 任务五工程当前值 |
|---|---|
| 底座 b | 10 ~ 170 |
| 前臂 f | 10 ~ 170 |
| 后臂 r | 10 ~ 170 |
| 夹爪 c | 5 ~ 130 |

这些是当前装配使用的配置值，换机械臂时需要核对，不能作为所有 meArm 的通用限位。

上电初始姿态：`b90 / f90 / r90`，夹爪按 `cMax` 闭合。

### 3.2 按键控制板（Arduino Uno R3，无屏幕，8 键）

按键一端接引脚、一端接 GND，使用芯片内部上拉，按下读到 LOW，无需外接电阻。

| 按键 | 引脚 | 发送字符 | 功能 |
|---|---|---|---|
| 按键1 | D4 | `N` | 循环执行 A/B/C 夹取放置 |
| 按键2 | D5 | `R` | 开始 / 停止录制 |
| 按键3 | D6 | `T` | 回放上次录制的动作 |
| 按键4 | D7 | `M` | 回到初始姿态 |
| 按键5 | D8 | `F` | 绘图模式切换（直线 / 三角形 / 五点直线 / 五点曲线） |
| 按键6 | D9 | `D` | 开始 / 暂停 / 继续 |
| 按键7 | D10 | `I` | 五点模式记录当前示教点，检查通过后保存 |
| 按键8 | D11 | `Q` | 绘制时尝试抬笔取消并回中，空闲时回中 |

| 项目 | 说明 |
|---|---|
| 屏幕 | 当前正式程序已去除屏幕依赖，按键状态通过 USB 串口输出 |
| 与机械臂通信 | 软串口 TX = D3，9600 8N1，只发单字符，不加回车换行 |
| 调试口 | 硬件串口 D0/D1，115200 |
| 去抖时间 | 30 ms（计时确认法） |

通信接线：本板 D3(TX) → 机械臂 D12(RX)，两板必须 **共地**。两端都是 Uno、都是 5V，直接连接，不需要分压。

> 两块板烧录都不需要拔线：机械臂的硬件串口 D0/D1 专供电脑，按键板走另一路软串口。

## 四、串口指令协议（任务五合并工程 `armDataCmd()`）

### 4.1 单字符指令（立即执行）

| 指令 | 功能 |
|---|---|
| `O` | 打开夹爪 |
| `S` | 关闭夹爪 |
| `H` | 提高运行速度（减小 DSD，有下限） |
| `L` | 降低运行速度（增大 DSD，有上限） |
| `P` | 打印当前四关节角度状态 |
| `A` / `B` / `C` | 执行对应物体的夹取—移动—放置动作 |
| `N` | 循环切换 A → B → C → A（按键1 使用） |
| `R` | 第一次按下开始录制，再次按下停止并保存（按键2 使用） |
| `T` | 回到录制起点并完整回放（按键3 使用） |
| `M` | 普通状态按预设顺序回中；绘图异常锁定时解除锁定并保持原位 |
| `K` | 正逆运动学往返自检 |
| `F` | 绘图模式循环切换（按键5 使用） |
| `D` | 开始 / 暂停 / 继续绘图（按键6 使用） |
| `I` | 五点模式记录示教点；失败不占点号（按键7 使用） |
| `Q` | 绘制时尝试抬笔取消并回中，空闲时回中（按键8 使用） |
| `U` | 继续暂停的绘图，串口备用指令 |
| `J` | 五点模式第1点记录后，开启 / 退出模型锁高示教 |
| `E` | 五点模式空闲时清空示教点，保持机械臂原位 |
| `1` ~ `6` | 依次标定 A取 / A放 / B取 / B放 / C取 / C放 |

绘图期间只接受 `D/Q/U/P/H/L`，防止其他流程抢占舵机。异常锁定不能直接恢复；用 `Q` 尝试抬笔取消，若无法抬笔，`M` 解除锁定后再用摇杆人工处理。

### 4.2 角度指令（需回车或换行结束）

| 形式 | 说明 |
|---|---|
| `x120,y60,z100` | 同时设置 x=底座、y=前臂、z=后臂的目标角度，三关节协同到位 |

这里的 x/y/z 是三个舵机的**角度**，不是笔尖的 XYZ 坐标。当前解析器不支持 `b90/f60/r100/c30` 形式的单关节角度命令；超出配置范围的目标会被拒绝，不会强行限幅后执行。

### 4.3 录制参数

采样间隔 200 ms，最多 80 帧（约 16 s），存满自动停止。数据保存在内存中，掉电丢失，重新录制会覆盖旧记录；录制期间禁止播放，少于两帧不播放。

### 4.4 任务五绘图模式与示教

| 模式 | 操作与轨迹 |
|---|---|
| 直线 | 无需示教，当前位置起笔，沿底座朝向向外画 30 mm 直线 |
| 三角形 | 无需示教，当前位置为首点，画边长 30 mm 等边三角形；经过首点后沿末边延长 25%（7.5 mm） |
| 五点直线 | 记录恰好 5 点，依次连接 1 → 2 → 3 → 4 → 5，不连接首尾 |
| 五点曲线 | 记录恰好 5 点，用 Catmull–Rom 插值平滑经过各点，不连接首尾 |

固定图形：用摇杆将笔尖轻放在纸面起点，选择模式后按 `D`。三角形第2、第3顶点各保持落笔至少 300 ms，延长终点停留 600 ms 再抬笔。绘制结束会抬笔，下一次绘制前需要重新放回纸面。

五点模式推荐步骤：

1. 按 `F` 选择五点直线或五点曲线；要重新示教时，先在空闲状态发 `E` 清空旧点。
2. 用原摇杆将笔尖轻触纸面，松杆后按 `I` 记录第1点，确认串口显示“已记录”。
3. 保持首点姿态，发送 `J` 开启锁高示教，再让全部摇杆回中。
4. 原底座轴控制 Y，原前臂轴控制 X，程序联动三个舵机保持首点模型 Z；此时后臂轴和夹爪轴忽略。
5. 每到一个点松开平面摇杆，再按 `I`；记满5点后按 `D`，整条路径检查通过才开始绘制。

不发 `J` 时仍是原来的独立关节控制，也可以直接示教。记录前会检查原始姿态、相对首点的高度差以及统一高度后的逆解；原始高度差超过 5 mm 或投影后越界时拒绝，不占用点号，调整后再按 `I`。

普通示教满5点后再次 `I`，会在新首点验证通过后替换旧组；锁高示教满5点后不会自动覆盖，可直接 `D` 执行。`J` 再次发送可退出锁高；开始绘图也会退出。固定图形不覆盖已有五点数据。

> 锁高指的是模型高度，不是实测纸面高度。示教移动时不自动抬笔，贴纸移动可能留下笔迹；尺寸、零位或笔尖安装有误时仍可能压纸或离纸，需要继续校准。

## 五、运动学与舵机映射

任务五工程内已实现任务四推导的正解与逆解，并用 `K` 指令做往返自检（正解 → 逆解 → 对比）。自检验证公式计算的一致性，不代表实物笔尖已达到相同精度。

运动学参数（取任务四文档名义值，单位毫米，实测校正后需替换）：

| 参数 | 含义 | 名义值 |
|---|---|---|
| L1 | 大臂轴心距 | 80 |
| L2 | 小臂轴心距 | 80 |
| L3a | 底座回转轴 → 肩轴 水平距离 | 60 |
| L3b | 腕轴 → 夹持参考点 水平距离 | 15 |
| h | 肩轴相对安装面高度 | 65 |

任务五当前使用的舵机指令与数学角度换算关系（依据纸面姿态修正，完整标定仍需核对）：

```
alpha = 180 - f      大臂倾角，f=90 时大臂竖直向上
beta  = f + r - 180  文档定义的小臂相对角，小臂绝对倾角为 r-90
theta = b   - 90     底座回转角，b=90 时指向 +X
```

任务五另加有效径向修正 `drawRadialCorrectionMm = -8.99`，由本机纸面两点的角度与 65 mm 弦长拟合，不表示已独立测得全部连杆尺寸。正解与逆解使用相同修正。

绘图流程：**舵机角 → 正解坐标 → XYZ 插值 → 逆解角度 → 三舵机更新**。约每 1 mm 采样，最小间隔 35 ms，再按最大角差与 DSD 延长等待；`H/L` 可调速度，没有严格恒速或完整加减速曲线。

开始前检查接近、落笔、绘图及收笔路径，抬笔高度从 10 mm 向 2 mm 逐级选择可行值；保留关节限位、0.5 mm 奇异边界余量及每步最大 3 度变化检查。“统一高度后不可达”会显示越界关节要求角度及范围，不能因各个示教点能到就认为整条连接轨迹也能到。
