# meArm-control-project

机械臂二面任务：基础控制、串口通信、自动夹取、动作录制和轨迹绘制。这是个人代码仓库，用于记录开发过程并作为提交材料。

---

## 硬件与接线

| 器件 | 引脚 |
|---|---|
| 底座舵机 | D9 |
| 前臂（大臂）舵机 | D8 |
| 后臂（小臂）舵机 | D6 |
| 夹爪舵机 | D7 |
| 底座摇杆 | A0 |
| 前臂摇杆 | A3 |
| 后臂摇杆 | A1 |
| 夹爪摇杆 | A2 |

- 主控：Arduino Uno
- 串口波特率：9600
- 舵机需要独立供电，并与控制板共地

## 串口指令

### 固定指令（单个字符，不区分大小写）

| 指令 | 功能 |
|---|---|
| `O` | 张开夹爪 |
| `S` | 闭合夹爪 |
| `H` | 提高速度 |
| `L` | 降低速度 |
| `P` | 输出当前角度 |

### 带参数的指令（需要以回车或换行结束）

| 指令 | 功能 |
|---|---|
| `x90,y90,z90` | 同时设置底座、前臂、后臂的目标角度 |
| `b90` / `f90` / `r30` / `c110` | 单独设置某个关节的角度 |

### 任务二、三相关

| 指令 | 功能 |
|---|---|
| `A` / `B` / `C` | 执行对应物体的夹取与放置 |
| `N` | 循环选择 A、B、C |
| `R` | 开始 / 停止录制 |
| `T` | 回放上一次录制的动作 |
| `M` | 回到初始姿态 |

### 任务五相关

| 指令 | 功能 |
|---|---|
| `K` | 运动学往返自检（正解 → 逆解 → 对比误差） |
| `V` | 舵机映射校验（当前舵机角度换算成坐标） |

## 编译与烧录

1. 用 Arduino IDE 打开对应任务目录下的 `.ino` 文件
2. 开发板选择 **Arduino Uno**，端口选择对应的 COM
3. 点击上传
4. 打开串口监视器，波特率设为 **9600**，行尾选"换行符"

任务五需要 `types.h` 和 `task5_drawing.ino` 在同一个目录里。

---

## 开发过程

按任务顺序推进，主要节点：

1. 基础控制：四路摇杆 + `O/S/H/L` + `x,y,z` 三关节协同
2. 自动取放：A/B/C 十步动作流程
3. 按键功能：循环、录制、播放、回中的状态机
4. 运动学：正解与逆解，用 `K` 指令做往返自检
5. 消除阻塞循环：把 `while + delay` 改成主循环按次推进，让串口在动作期间也能响应
6. 内存优化：去掉冗余字段、字符串改存 Flash，SRAM 占用从 95% 降到 36%

## 已知限制

- 舵机没有位置反馈，`P` 打印的是设定角度，不是实测角度
- 录制数据存在 SRAM 里，掉电会丢失，最多 80 帧（约 16 秒）
- 大臂行程有限，机械臂最低只能压到水平面以上一定角度，绘图区域受限
- 任务五的平滑曲线（子任务 5）尚未实现
