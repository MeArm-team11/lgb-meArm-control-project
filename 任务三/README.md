# 任务三：四按键控制、动作录制与播放

在任务二基础上增加循环选择、录制、播放和回中功能。目前先用串口指令调试，实体按键和双板通信待联调。

## 已实现功能

以下为当前代码已实现的内容，不代表全部通过实物验收。

| 指令 | 功能 |
| --- | --- |
| `N` | 按 A → B → C → A 循环选择物体；自动取放调用暂未启用 |
| `R` | 第一次开始录制，再次发送停止录制 |
| `T` | 先回到录制起点，再按记录时间播放动作 |
| `M` | 按预设顺序回到初始姿态 |

录制保存四个舵机的设定角度和时间，采样间隔设为200毫秒，最多80帧，存满自动停止。数据保存在内存中，重启后丢失；重新录制会覆盖旧记录。录制期间禁止播放，少于两帧时不播放。

保留摇杆控制、`O/S` 开合夹爪、`H/L` 调速、`P` 查询角度和 `x角度,y角度,z角度` 协同控制。

## 简单测试

1. 打开 `Task_3_copy_20261005/Task_3_copy_20261005.ino`，按实际板型编译、烧录，串口波特率设为 `9600`。
2. 发送 `R`，用摇杆操作超过10秒，再发 `R` 停止，发送 `T` 检查回放。
3. 发送 `M` 检查回中，连续发送 `N` 检查 A/B/C 选择顺序。

录制时暂时只用摇杆操作及 `R` 开始、停止，不混发其他运动指令，避免阻塞采样。测试前确认运动路径安全。
