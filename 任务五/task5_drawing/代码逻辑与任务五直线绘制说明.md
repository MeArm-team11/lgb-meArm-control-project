# meArm任务一至五代码逻辑与直线绘制修改说明

适用文件：本目录的 `task5_drawing.ino`、`types.h`。说明对应 2026 年 10 月 15 日修改版，不以项目根目录旧 README 的“待实现”状态为准。

本次保留了任务一至三的主要控制流程以及任务四的正逆运动学公式，替换了任务五的关节角插值实现。任务五的直线和三角形以当前纸面位置为起点生成固定尺寸顶点，无需示教；五点直线与五点曲线使用5个示教点。两种来源共用“正解坐标 → XYZ轨迹 → 逆解角度 → 舵机输出”流程。底座可以转动，但大小臂必须按逆解同时补偿，才能让目标点沿直线移动。实际舵机仍是开环控制，模型中的直线不等同于实物已经达到同样精度。

## 一 文件和数据结构

`task5_drawing.ino` 是集成工程，包含初始化、串口和摇杆输入、任务二取放、任务三录制回放、任务四运动学、任务五绘图及主循环。`types.h` 放在主程序包含位置，保证 Arduino 自动生成函数声明时能够识别自定义类型。

| 类型 | 字段 | 用途 |
|---|---|---|
| `JointPoint` | `b, f, r`，整数角度 | 一组底座、前臂、后臂舵机指令角；用于取放标定、绘图示教 |
| `ActionData` | `getPoint, putPoint, open, close` | 一件物体的取放姿态和夹爪角度 |
| `RecordFrame` | `b, f, r, c`，四个 byte | 录制一帧，Uno 上每帧4字节 |
| `CartesianPoint` | `x, y, z`，三个 float | 任务四模型中的末端参考点坐标，单位毫米 |

`bPos/fPos/rPos/cPos` 是程序最近写给舵机的角度，不是编码器测得的实际角度；`targetB/F/R/C` 是通用运动器的目标角度。两组值相等只表示指令推进完成。

## 二 总体运行结构

### 2.1 初始化

`setup()` 完成四个舵机的引脚绑定，初始化电脑串口和按键板软串口，再写入初始姿态。舵机引脚为底座D9、前臂D8、后臂D6、夹爪D7；摇杆为A0、A3、A1、A2；按键板发送端接机械臂控制板D12，波特率9600，两板共地。

启动姿态为 `b=f=r=90`，夹爪使用 `cMax`。上电写初始角度没有使用渐进运动；它可能使机械臂立即向初始姿态运动。改变装配后，应先检查初始姿态是否适合实际机构。

### 2.2 主循环

`loop()` 按以下顺序执行：

```text
readCmd              读取电脑串口
readBtnCmd           读取按键板串口
stepJointTarget      推进任务一至三使用的通用角度运动
homeCtrl             推进回中流程
actionCtrl           推进任务二取放流程
playCtrl             推进任务三回放流程
drawCtrl             推进任务五XYZ轨迹
joyCtrl/planeTeachCtrl 仅在自动流程空闲时二选一：原关节摇杆/任务五锁高摇杆
recordCtrl           如正在录制，检查是否到采样时间
```

这些控制器通过状态变量和 `millis()` 判断时机，每次只推进一小步。任务五运行时由 `drawActing` 独占关节输出，不通过通用运动器再对关节角进行插值，避免两套轨迹算法叠加。绘图开始前的完整预检是一次同步计算，在预检结束前不会发出绘图运动指令；因此不能把整个程序称作完全无阻塞。

| 状态变量 | 管理内容 |
|---|---|
| `motionState` | 通用角度运动是否进行中 |
| `homeStep` | 回中阶段 |
| `actionStep` | 取放的第1至14步 |
| `playStage` | 回放前回到首帧，或者正在回放 |
| `recording` | 是否记录当前指令角 |
| `drawActing` | 绘图接近、画线、暂停、收笔或取消 |
| `planeTeachActive` | 任务五可选模型锁高示教，J开关，默认关闭 |

串口指令入口负责阻止多个自动流程互相抢占。绘图期间允许 `D/Q/U/P/H/L`，禁止改变示教点、模式、夹爪或另开取放回放任务；摇杆也被暂时禁用。异常锁定时另允许 `M` 解除锁定并保持位置，见任务五异常说明。

## 三 任务一 基础控制和多舵机控制

### 3.1 底层输出

`limitData()` 把整数限制在上下界；`servoWrite()` 按舵机名称调用对应的 `Servo.write()`，同时更新位置变量。当前底座、前臂、后臂限位均为10至170度，夹爪为5至130度。这些是代码配置值，不代表每台机械臂均能安全使用整个范围。

通用目标运动使用 `startJointTarget()`：先拒绝忙碌请求和越界目标，再保存目标并把 `motionState` 置1。这里越界时直接拒绝，不会把目标偷偷改成限位角。

`stepJointTarget()` 每隔 `DSD` 毫秒，让每个未到目标的舵机靠近目标1度；较早到达的关节停住，其余继续。所有关节达到目标指令后结束运动。因此它是多个关节共同推进，但并不保证所有关节同时到达，也不保证末端直线。这正是任务五没有继续复用它画线的原因。

### 3.2 摇杆

`joyDir()` 以512为中心、100为死区判定正向、反向或不动。`joyCtrl()` 通过 `moveJoint()` 每次增减1度，调用间隔为 `DSD`。松开摇杆后，落在死区内则不更新角度。

### 3.3 指令和速度

| 输入 | 行为 |
|---|---|
| `O` / `S` | 夹爪张开 / 夹紧 |
| `P` | 输出当前四个设定角 |
| `H` / `L` | `DSD` 减小 / 增大5ms，限制在2至60ms |
| `x120,y60,z100` 加换行 | 给底座、前臂、后臂指定120、60、100度 |

这里的 `x/y/z` 只是旧串口协议的角度字段名，**不是毫米坐标**。当前 `readCmd()` 没有独立实现 `b90/f60/r100/c30` 形式的数字角度命令，不能因为旧 README 提过就认为可用。

本次修复了旧解析器的一个问题：数字1至6原来无论是否正在接收整行都会被识别为标定指令，导致 `x120,y60,z100` 中的数字被截走。现在仅在行缓冲为空时识别单字符命令；开始接收整行后，后续字符保留到换行再统一解析。

## 四 任务二 标定和自动取放

### 4.1 数据和标定

`actionA/actionB/actionC` 分别保存三组 `ActionData`。用摇杆摆到位置后，单独发送1/2记录A取/放点，3/4记录B取/放点，5/6记录C取/放点。`calibratePoint()` 把当前 `bPos/fPos/rPos` 写入对应点位。

数据只存在RAM，复位丢失。当前 `actionReady[3]` 在任一取物或放置点记录后就置真，并且没有在 `doAction()` 中检查。因此它既不表示两个点都已标定，也不阻止未标定动作。默认点位都是90度，首次使用任务二必须先标定取点和放点。本次没有重构任务二的标定有效性逻辑。

### 4.2 14步流程

`doAction()` 保存本次动作参数，启动第1步；`startActionStep()` 根据 `actionStep` 设置下一组目标；`actionCtrl()` 等待目标指令完成，再停顿 `actionWait=300ms`，切换到下一步。

| 步骤 | 实际控制内容 |
|---|---|
| 1 | 大小臂到 `fHigh=120, rHigh=85`，底座保持 |
| 2 | 张开夹爪 |
| 3 | 底座转到取物点方向 |
| 4 | 大臂到“取物点f减去approachLift”，小臂到取物点r |
| 5 | 大臂到取物点f |
| 6 | 夹爪夹紧 |
| 7 | 大臂到“取物点f减去liftAmount” |
| 8 | 大小臂到 `fFold=110, rFold=60` |
| 9 | 底座转到放置点方向 |
| 10 | 大臂到“放置点f减去approachLift”，小臂到放置点r |
| 11 | 大臂到放置点f |
| 12 | 张开夹爪 |
| 13 | 大臂到“放置点f减去liftAmount” |
| 14 | 大小臂回收拢姿态 |

`approachLift=22` 和 `liftAmount=35` 的单位是度，不是毫米。中间部分角度会经过 `limitData()` 限幅。

旧代码将第5、7、11、13步称作“垂直下降/抬升”，但只改变一个舵机角通常会引起水平位置和高度同时变化。这里是经验角度取放，不是任务四逆解驱动的竖直轨迹，升降方向和距离都要按实际姿态核对。按用户要求，本次保留任务二原有代码、注释和动作，不处理其升降方式。

`A/B/C` 直接执行对应动作；`nextAction()` 响应 `N`，每次按键依次选择A、B、C。它不是一次按下就连续搬运三件物体。

## 五 任务三 按键 录制 回放和回中

### 5.1 录制

`recordCmd()` 响应 `R`。第一次开始时清空帧数、保存起始帧；再次按下时保存停止姿态并结束。`recordCtrl()` 每200ms调用 `saveFrame()`，最多80帧，满后自动停止。每帧仅保存四个byte角度，共320字节。

第0至79帧按理想200ms间隔对应约15.8秒跨度，可概括为约16秒容量。帧内不保存时间戳，因此回放假设固定周期。手动停止时追加的最后一帧可能不恰好位于200ms边界，回放时间会有少量偏差。录制内容也是指令角，不能记录舵机真实滞后或外力造成的位移。

### 5.2 回放

`playStart()` 拒绝正在录制或少于两帧的回放请求。若当前位置与首帧不同，先执行底座、大小臂、夹爪分阶段返回首帧；否则直接播放。

`playCtrl()` 在回放阶段按 `playIndex * recordStep` 的时间向四个舵机写入帧数据。这里直接写入每帧目标，没有帧间XYZ轨迹规划，也没有通用运动器的一度一度推进。因此任务三是角度记录与重现，任务五是按几何轨迹规划，两者用途不同。

### 5.3 回中

`goHome()` 启动回中，`homeCtrl()` 依次让大小臂回中、底座回中、夹爪回中，每段完成后停顿300ms。任务五正常结束只抬笔并停在终点上方；任务五取消时先检查并执行竖直抬笔，再调用这个原有回中流程。

原有回中流程没有做全程碰撞检测。任务五预检保证的是取消抬笔段满足模型可达条件，不能把它理解为后续回中的每个机械部件都已验证无碰撞。

## 六 任务四 正逆运动学及舵机映射

公式依据项目任务四 Word 文档第4节正解、第5节逆解及其上肘分支。已核对文档文字和公式内容。

### 6.1 参数和坐标

| 参数 | 当前值mm | 含义 |
|---|---:|---|
| `L1` | 80 | 大臂轴心距 |
| `L2` | 80 | 小臂轴心距 |
| `L3a` | 60 | 回转轴到肩轴的水平偏移 |
| `L3b` | 15 | 腕轴到夹持参考点的水平偏移 |
| `h` | 65 | 肩轴相对安装面的高度 |

`theta` 为底座回转角，`alpha` 为大臂倾角，`beta` 为文档定义的小臂相对角。函数接口用度，三角函数调用前转换为弧度。

### 6.2 正解

`forwardKinematics()` 实现：

```text
R = L3a + L1*cos(alpha) + L2*sin(alpha+beta) + L3b
X = R*cos(theta)
Y = R*sin(theta)
Z = h + L1*sin(alpha) - L2*cos(alpha+beta)
```

`jointToCartesian()` 按纸面实测数据支持的绝对小臂倾角映射换算（已替换旧README的相对角映射）：

```text
theta = b - 90
alpha = 180 - f
beta  = f + r - 180
```

其中小臂绝对倾角 gamma=r-90，而任务四定义 gamma=alpha+beta-90，所以 beta=f+r-180。先调用正解，再沿底座朝向加上任务五有效径向修正 drawRadialCorrectionMm=-8.99mm。该修正由用户65mm弦长数据拟合，未改任务四的名义尺寸；正反向必须应用同一修正。绝对倾角模型由当前纸面观测支持，但没有完成独立实机验证或全参数标定。

### 6.3 逆解

`inverseKinematics()` 实现：

```text
R = sqrt(X² + Y²)
theta = atan2(Y,X)
r = R - L3a - L3b
z = Z - h
d = sqrt(r² + z²)
phi = atan2(z,r)
gammaS = acos((L1²+d²-L2²)/(2*L1*d))
eta = acos((L1²+L2²-d²)/(2*L1*L2))
alpha = phi + gammaS
beta = eta - 90°
```

三角函数得到弧度后转换为度。选用文档给出的上肘分支，未引入另一支解自动切换。

新增检查：拒绝NaN/无穷数；拒绝回转轴附近 `R<ARM_EPS` 的底座角不唯一情况；拒绝 `d<ARM_EPS` 的肩角不唯一和除零情况；拒绝超出两杆长度条件的点。`ARM_EPS=0.001` 用于微小浮点容差，`clampUnit()` 仅在通过距离检查后处理反余弦的边界舍入。

`cartesianToJoint()` 先从径向距离中减去 drawRadialCorrectionMm，把实际工具有效坐标换回任务四名义坐标，再调用任务四逆解。绘图中要求离伸直/折叠边界至少0.5mm，然后把数学角转换回舵机角：

```text
b = theta + 90
f = 180 - alpha
r = alpha + beta
```

先检查浮点角度限位，再用 `round()` 四舍五入，避免先强行限幅再假装坐标可达。

### 6.4 自检能证明什么

`K` 运行 `kinematicsTest()`，检查数学角 → 正解 → 逆解的一致性。它能帮助检查公式和角度定义，但不能证明实体尺寸、舵机零位、笔尖安装或实际轨迹都正确。若同一套错误尺寸同时用于正解和逆解，往返仍可能通过。

## 七 任务五 直线绘制的修复

### 7.1 原逻辑为何画弧

旧 `buildLinePath()` 在舵机角度之间计算：

```text
b(t) = b0 + (b1-b0)*t
f(t) = f0 + (f1-f0)*t
r(t) = r0 + (r1-r0)*t
```

这只能使关节角按比例变化。正解含有三角函数，角度线性变化一般不会得到坐标线性变化。特别是两端f、r相同而b不同，整个路径只有底座转动，R和Z不变，俯视轨迹就是圆弧。

旧代码还存在四个相关问题：

1. `pathBuf` 满120点就返回，前半段可能被当作完整路径执行。
2. 使用“增量加0.5再转int”处理负方向角度变化，存在不对称取整，末端可能少走1度。
3. 开始绘图时抬臂和转底座同时进行，无法保证先离开纸面。
4. 通用忙碌判断会把运动中的 `D/Q/U` 拦下，且两点之间可能接受改变模式、示教点等指令。

### 7.2 新实现保留与替换范围

保留舵机驱动、摇杆、任务二三主要流程、运动学主体公式、按键字符和四种模式。替换旧的 `PathPoint/pathBuf/buildLinePath/buildCurvePath` 及任务五执行状态机；新增 `CartesianPoint`、角度坐标映射、逐段插值和路径预检。

不需要删除整个任务五工程，更不需要重写任务一至四。需要删除的是旧的“在关节角上生成绘图轨迹”的核心路径实现。

### 7.3 固定图形与五点示教

直线、三角形模式不再要求按I记录顶点。先用摇杆将笔尖轻放到纸面起点，再按D，以当前位置作为此次图形的原点和纸面高度。默认直线长30mm，等边三角形边长30mm；修改 `fixedLineLengthMm` 或 `fixedTriangleSideMm` 可改变尺寸。没有自动探测纸面或自动校准Z的功能，若在悬空位置启动，图形也会在该高度执行。

起笔时底座朝向定义局部向外方向u，水平逆时针垂直方向为v：

```text
u = (cos(theta), sin(theta))
v = (-sin(theta), cos(theta))
直线顶点：P0，P0 + length*u
三角形顶点：P0，P1=P0 + side*u，P2=P0 + side/2*u + sqrt(3)/2*side*v
延长终点：P3=P0+0.25*(P0-P2)，路径P0→P1→P2→P0→P3
所有固定图形顶点Z均为起笔位置的模型Z。
```

“固定”指形状、尺寸以及相对底座的方向固定，不表示使用尚未标定的世界绝对坐标。每次D重新启动时取当时位置；绘图结束会抬笔，所以再次绘图前应将笔尖放回期望的纸面起点。暂停恢复不会重新取起点。

五点模式空闲时按I，`teachRecordPoint()` 先打印候选b/f/r和模型坐标，再检查原始姿态、5mm高度差和统一高度后的逆解；通过才保存。失败不占用点号、不改变旧数据、不移动机械臂，调整后再I仍记录同一个点号。最多5点，普通关节示教下第6次按I会尝试以当前点开始新组，只有验证通过才替换旧组；J锁高示教中满5点则提示D执行，不自动覆盖，先J退出后可重新记录；数据复位丢失。固定图形模式按I只提示无需示教，不改变已有点。自动运动、绘图、录制、回放期间不接受示教。

| 模式 | 输入来源 | 路径 |
|---|---|---|
| 直线（LINE） | 当前位置，默认30mm长度；无需示教 | 向外直线一段 |
| 三角形（TRI） | 当前位置，默认30mm边长；无需示教 | 等边三角形1→2→3→1，再沿末边延长25% |
| 五点直线（POLY） | 正好5个示教点 | 1→2→3→4→5，不闭合 |
| 五点曲线（CURVE） | 正好5个示教点 | 平滑经过1→2→3→4→5，不闭合 |

F依次循环四种模式，切换不清空示教点。`drawPointCount` 表示本次轨迹有几个顶点，`teachCount` 只表示保存了几个示教点；二者独立，固定图形不会覆盖示教数据。固定图形点和五点示教点都经过逐点及全路径检查，未通过不会输出运动指令。

五点模式先检查每个原始示教姿态是否能由逆解还原（允许1度差），再以第1点的模型Z作为本次绘图平面。后续点保留原始模型X/Y（J锁高记录的点改用缓存的未取整目标X/Y），Z统一替换为第1点的Z。只修改本次 `drawPoint`，原始 `teachPoint` 的b/f/r始终保留。

```text
纸面Z = 第1点的模型Z
绘图点i = (普通示教原始Xi或锁高缓存Xi, 普通示教原始Yi或锁高缓存Yi, 纸面Z)
```

每次I记录时打印原始Z、锁定Z和原始高度差，不再要求用摇杆把所有显示Z调成完全一样。当前 `drawMaxPlaneCorrectionMm=5.0f`，任一点原始高度相对首点偏差超过5mm，在记录时直接拒绝，启动时仍重复校验；不是无条件忽略高度。退出J锁高后，第6次I清空重记时，纸面Z随新的第1点重新确定，锁高缓存标记同时清除。

投影后角度通常与原示教角度不同，因此不能再用“投影后的逆解必须还原原角度”判断；需要重新检查投影点的可达性、关节限位和整条路径。即使所有原始点可达，投影后的某点或中间段也可能不可达，此时保持原位并报告原因。

这项改变解决的是规划层面的统一高度，不是自动标定，也不是力控。首点必须轻触纸面，其余点也应在纸面附近定位；不要悬空记录后依赖高度修正来自动找纸。模型仍有偏差时，理论等高不保证实物一直贴纸。若有悬笔、压笔或水平位置偏差，应继续检查标定和笔尖安装，不能单纯增加5mm上限。
### 7.4 轨迹生成

`segmentEnds()` 确定当前阶段和线段的两个端点，`segmentSamples()` 计算采样数，`segmentPoint()` 计算采样坐标。

直线公式为：

```text
N = max(1, ceil(端点距离 / drawSpacingMm))
t = k / N
X(t) = X0 + (X1-X0)*t
Y(t) = Y0 + (Y1-Y0)*t
Z(t) = Z0 + (Z1-Z0)*t
```

当前 `drawSpacingMm=1mm`，每段端点k=N一定被计算到。重复点使用N=1，避免除零。每个点调用任务四逆解，再转换为三个舵机角。底座是否转动、大小臂怎样补偿由坐标关系确定。

例如示教 `(b,f,r)=(70,120,90)` 和 `(110,120,90)`，采用本次修正后的映射，两端到回转轴距离约186.01mm。若继续按角度插值，中点为 `(90,120,90)`，径向距离仍为186.01mm；端点连线中点的X约174.792mm，差约11.218mm。新方式先算出连线中点，再重新计算f和r，使径向距离随底座角同步改变。

曲线也改成XYZ插值，采样数量用相邻控制点距离的保守导数上界估算。曲线可能超出控制点围成的区域，因此所有中间样本都需要检查；不能因为控制点可达就省略检查。当前每段采样数有4096上限，超出会拒绝，而不是截断。

### 7.5 从当前位置接近和结束

`drawStart()` 先独立检查纸面绘图段，再从10mm开始，以1mm为步长尝试降低抬笔高度，最低2mm；选用接近和收笔路径全部通过预检的高度。执行路径为：

```text
当前位置
  → 保持X/Y，抬到最高示教点或当前位置之上选定高度
  → 在该高度移动到起点正上方
  → 保持起点X/Y，降到起点
  → 沿所选模式绘图
  → 保持终点X/Y，竖直抬高选定高度
  → 停止并恢复空闲
```

固定图形在当前位置起笔，仍先进行抬笔、回到同一位置的落笔流程；五点模式需要悬空移动到第1示教点。三角形先经过第1点（下发与起笔一致的角度），再沿第3点到第1点的方向多画原边长25%，默认7.5mm。延长段结束后保持落笔至少600ms，并从延长终点抬笔；其余模式没有延长或该停顿。接近和收笔也通过XYZ插值计算，并非只调某个舵机角。

10mm是首选抬笔高度，2mm是最低允许值，启动时会打印最终选定值。若最低高度仍不能满足要求，保持原位；不会取消抬笔后强行画线。取消绘制时也重新检查10至2mm范围内的抬笔路径。所选高度只是当前模型中的Z增量，实际笔尖离纸间隙仍需实测。预检只检查模型可达性、限位、奇异余量和角度步长，没有建立桌面以外的障碍物或连杆碰撞模型，不能保证完整机械臂各部件不碰撞。

### 7.6 执行状态机

| `drawActing` | 含义 | 处理 |
|---|---|---|
| 0 | 空闲 | 可示教、换模式、启动 |
| 1 | 接近起点 | 三段：抬笔、悬空平移、落笔 |
| 2 | 绘图 | 逐段逐样本输出逆解角度 |
| 4 | 暂停或异常锁定 | 不发新轨迹角度 |
| 5 | 正常收笔 | 终点竖直抬笔后空闲 |
| 6 | 取消收笔 | 从当前指令位置竖直抬笔后调用回中 |

`drawSegment` 保存段号，`drawSample` 保存已发出的样本数，`drawSamples` 保存该段总样本数。`beginDrawPhase()` 初始化阶段，`drawCtrl()` 每次最多发一个采样点。每个点的三个角度在同一轮循环中更新。

没有位置传感器，因此暂停停止的是继续下发新目标；舵机可能仍会向最近一次收到的目标完成少量运动。不能将软件暂停描述为机械臂瞬间物理停止。

### 7.7 速度控制

任务五使用以下规则：

```text
角度差 = max(|新b-旧b|, |新f-旧f|, |新r-旧r|)
本次目标写出后等待时间 = max(drawStepMs, 角度差*DSD)
```

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `drawSpacingMm` | 1mm | 直线采样间距上限，越小采样越密 |
| `drawStepMs` | 35ms | 两次目标更新的最小等待时间 |
| `DSD` | 默认35ms/度 | 依据最大关节变化量追加等待，H/L调整 |
| `drawMaxJointStep` | 3度 | 逐样本角度跳变量上限，超出拒绝 |

在每步约1mm、没有额外角速度约束和计算开销时，35ms节拍对应约28.6mm/s的目标采样速度。这只是规划更新频率推算，实际速度还受段尾间距、取整、关节等待、串口耗时和舵机响应影响。H降低DSD后若已经被35ms下限约束，速度不会继续增加。

程序没有梯形/S曲线加减速，也不提供严格恒定的笛卡尔速度。三角形第2/3个顶点下发角度后，各等待至少 `triangleCornerHoldMs=300ms` 再转向；计时期间仍可暂停和取消。三角形延长后的最终点额外等待 `triangleCloseHoldMs=600ms`，只改变收笔前停留时间，各边画线速度保持原规则。等待采用millis计时，D暂停、U恢复、Q取消仍可响应；暂停恢复后重新计满600ms，取消则进入抬笔流程。当前策略优先保证采样密度、有限角度跳变和可调等待时间；高速绘图还需增加更完整的时间参数化和实机标定。

### 7.8 异常处理

| 情况 | 检查位置 | 行为 |
|---|---|---|
| 正在录制/回放/取放/通用运动 | `drawStart()` | 拒绝启动 |
| 五点模式点数不符 | `drawStart()` | 提示需要正好5点并保持原位；固定图形不检查示教点数 |
| 原始示教高度差超过5mm | `validateTeachProjection()`，由记录/启动共用 | 记录时拒绝且不占点号；启动时复检，显示点号、原始高度差和允许修正量 |
| 统一高度后不可达或超限 | drawStart() | 保持原位，提示投影后的点号与具体原因 |
| 逆解分支无法还原示教姿态 | `drawStart()` | 拒绝该示教组 |
| 中途点不可达、关节越界或距奇异边界不足0.5mm | `validateSegment()` | 开动前拒绝，分别报告不可达、关节限位或奇异余量 |
| 相邻采样角度跳变超过3度 | `validateSegment()` | 开动前拒绝，检查采样和姿态 |
| 运行时再次检查失败 | `drawCtrl()` | 停止发新目标，进入异常锁定 |
| 正常暂停 | `D` | 保存原阶段和段内进度，再D或U恢复 |
| 正常取消 | `Q` | 重新验证当前点的抬笔段，通过后抬笔再回中 |
| 10至2mm均不能通过预检 | `drawStart()` | 提示绘图段可达但接近/收笔无法满足最低高度，保持原位 |
| 取消时无法抬笔 | `drawCancel()` | 保持位置并锁定，不强行回中 |
| 异常锁定后按U/D | `resumeDrawing()` | 拒绝从失效轨迹继续 |
| 异常锁定后按M | 指令入口 | 解除锁定且不发回中运动，恢复摇杆以人工处理 |
| 绘图时输入其他运动/模式/示教指令 | 指令入口和角度行解析器 | 拒绝，防止轨迹被覆盖 |

预检逐个检查的是离散采样点及相邻角度跳变量，不是对实际舵机连续运动、接触力和全机构碰撞的数学证明。任务五不使用强行限幅来让不可达点“看起来成功”。

## 十 固定图形与五点模式操作

1. 上传同一目录的 `.ino` 与 `types.h`，串口9600。
2. 默认直线模式：用摇杆将笔尖轻放在希望开始绘图的纸面位置，按D，向当前底座朝向的外侧画30mm直线。
3. F切到三角形：先把笔尖轻放在纸面顶点，按D，绘制边长30mm的等边三角形，第2/3顶点各停留至少300ms再转向，经过起点后沿最后一边继续7.5mm，停留600ms再抬笔。
4. 两种固定图形均不需要I记录点。图形结束会抬笔，再画前要重新放到纸面；程序不自动判断是否接触纸面。
5. 五点直线/五点曲线：先F切到对应模式，第1点轻触纸面并按I确定模型纸面Z；推荐随即发送J开启锁高示教（详见第十四节），松开所有摇杆后用底座轴调Y、前臂轴调X，每次松杆按I记录。也可以不启用J，沿用普通关节示教，其余点在纸面附近定位并按I，不必追求显示Z完全相同。原始高度差不超过5mm时按D，程序保留X/Y并统一绘图Z，再进行整条路径预检。两种模式都不连接首尾。
6. 绘制中D暂停，再D或U继续；Q取消，先抬笔再回中。路径越界时保持原位，换起点或修改已核实的尺寸配置，不能靠取消限位解决。
7. 异常锁定且Q无法抬笔时，M解除锁定并保持原位，随后用摇杆处理；此时M不是普通自动回中。

## 十一 实测反馈与两点校验

早先报告的 `(203.38,10.66,155.09)` 等XYZ是旧代码计算值，并非实测坐标。当时5mm余量确实错误拒绝了该旧模型点，且旧模型下10mm抬笔不可达。本次已按实际舵机姿态修正映射，因此旧XYZ、旧姿态反解及“选定3mm”不再作为当前版本标定依据。0.5mm数值余量、10至2mm抬笔预检和详细错误分类仍保留。
两个真实纸面点可以做初步一致性检查，最简记录如下：

```text
点1：b=___°，f=___°，r=___°
点2：b=___°，f=___°，r=___°
尺子量出的纸面两点距离：___mm
两点都在同一张平整纸面，笔尖轻触纸面：是/否
笔的夹持位置保持不变：是/否
```

在各点位置发送P可以获取当前指令角；P打印的x/y/z分别对应b/f/r，仍是角度。新版I示教日志则直接打印b/f/r，并将正解坐标标记为“模型X”。不要把程序算出的XYZ或点间距填成实测值。

最好选择大小臂角度也有变化的两点。如果两点只有底座角不同，大小臂角完全相同，数据不足以检查大小臂映射。仅两组角度无法唯一求出全部杆长、偏移和舵机零位；加上实测距离后，可以比较模型是否预测两点等高、线长是否与尺子测量一致。若要定位并修正具体尺寸或映射，通常还需要轴心距、侧视照片或更多独立姿态；不能凭这两个点随意修改多个参数以凑出结果。
## 十二 根据实际纸面姿态修正任务五映射

用户提供的观测（单位度，夹爪均c=130）：

| 记录 | b | f | r | 观测 |
|---|---:|---:|---:|---|
| 早先近点A | 90 | 108 | 10 | 笔尖接触纸面 |
| A只转底座 | 144 | 108 | 10 | 笔尖接触纸面 |
| 早先远点C | 100 | 142 | 51 | 向前伸，笔尖仍接触纸面 |
| 新近点D | 114 | 113 | 10 | 笔尖接触纸面 |
| 新近点E | 80 | 113 | 10 | 与D在纸面，两点距离65mm |

旧映射 beta=90-r 预测A与C高度相差约115.46mm。候选映射 beta=f+r-180 预测A高62.30mm、C高63.91mm，差约1.61mm，更符合纸面观测，因此在任务五中采用这一映射。其物理含义是后臂舵机控制小臂绝对倾角，而文档beta是两杆的相对角；不能把二者直接相等。任务四公式本身以及任务一至三的角度控制保持不变。

按65mm为D/E的平面直线距离、底座指令角差34度等于实际角差、两杆轴距均80mm计算：

```text
R = 65 / (2*sin(34°/2)) = 111.1599mm
大臂水平投影 = 80*cos(180°-113°)
小臂水平投影 = 80*sin(10°)
有效固定水平偏移 = R - 两杆水平投影 = 66.0095mm
任务五径向修正 = 66.0095 - (60+15) ≈ -8.99mm
```

该数据只能拟合合计偏移，不能单独认定L3a、L3b的实际值，更不能由此证明底座角度比例、杆长和工具安装都准确。程序用独立 drawRadialCorrectionMm 表达这项初步拟合，不把它冒充实测杆长。拟合后预测65.0003mm，是训练数据的一致性结果，不是独立精度验证。

最新D/E均处于rMin=10度。它们之间的弦线中点需要 b≈97、f≈111.98、r≈7.43度，超出既有后臂下限。端点能到不等于整段直线都能到，程序保留rMin=10并拒绝这段轨迹，不自动放宽实机限位。最新固定直线不再连接这两个示教点，而是从当前点向外生成30mm线段；五点模式若包含该越界线段仍会拒绝。

还存在未解决的纸面高度残差：新近点D的模型Z≈59.86mm，早先远点C≈63.91mm，差约4.05mm。如果笔的安装和纸面都未改变，这说明剩余尺寸/零位/映射误差或测量重复性仍需确认。最新五点模式允许把不超过5mm的原始高度差投影到首点平面，但保留原始角度和高度日志；这不是对上述标定残差的修复，仍不能据此宣称实物高度已准确。下一步应使用同一次固定笔安装，重新采集一组近远纸面点的b/f/r和实测间距，作为独立核对。尤其不要把旧软件输出XYZ当作实测值。
## 十三 三角形最后一边延长四分之一

按用户要求，三角形最后一边从第3点返回第1点后，沿同一方向继续原边长的25%。默认边长30mm，多画7.5mm，最后一笔合计37.5mm。参数 `triangleLastEdgeExtraRatio=0.25f`，设为0可关闭延长。该做法会使理想轨迹在起点外多出一段线，是用户要求的笔迹补偿，不代表已经校准机械误差。

实现将最后一笔分成第3点→第1点和第1点→延长终点两段，连续绘制；经过第1点时不抬笔、不等待600ms，仍输出与起笔相同的角度。额外终点以 `Pextra=Pstart+0.25*(Pstart-Pthird)` 计算，保持纸面Z。延长完成后才按 `triangleCloseHoldMs=600` 保持落笔，再从额外终点竖直收笔。暂停、继续、取消仍有效。

预检涵盖新增段和新增收笔位置，不允许直接绕过限位。接近后臂10度下限的起点，原三角形即使能画，向起点内侧延长也可能不可达；此时整个绘制请求被拒绝，保持原位，需要换起点。固定直线、两种五点模式和任务一至三不增加延长。

## 十四 三角形转向停顿与可选锁高摇杆示教

### 14.1 为什么第2点可能发圆

原路径几何已按直线分段，但第2点下发后只等待常规采样间隔，就开始下一边；实体舵机滞后、机械回差或笔尖弹性会使实际转向发生在到点之前。新版本在第2/3顶点分别下发精确逆解角后保持落笔至少300ms（若正常角度间隔更大则取更大值）。参数 `triangleCornerHoldMs`；不是在顶点附近插入曲线，也不更改顶点位置。暂停恢复后重新等待完整间隔，Q仍可立即进入取消抬笔。

保留原先要求的末边延长25%：经过第1点后继续7.5mm，延长终点停600ms再收笔。不保证300ms能消除全部实物圆角；没有位置反馈，不知道舵机是否真正到位。若仍发圆，可先用L降低速度并检查机械间隙、笔的刚性与压纸力度。长时间停笔也可能形成墨点，需要实机折中。

### 14.2 五点模式推荐操作（J是新增串口字符）

1. 用F选择五点直线或五点曲线。开始一组新示教，串口应显示“示教点1”；旧组已满5点时，普通模式再按I会在验证通过后记录新第1点。若旧组只有部分点，可在五点模式空闲时发E清空重教，保持原位。
2. 使用原摇杆把笔尖轻触纸面，松杆并按I记录第1点。夹爪应已固定笔，不要在后续改变夹持角。
3. 保持该姿态不动，从电脑串口发送单字符J（9600波特率）。仅允许五点模式、空闲、恰有1点且当前指令角仍等于首点时开启；不会自动把机械臂拉回旧首点。
4. 先松开全部摇杆回中。启用后原底座轴A0控制世界Y，原前臂轴A3控制世界X；它们不再分别控制某一个舵机，实际由逆解联动三个舵机。后臂轴A1和夹爪轴A2在此状态下忽略。每轴方向沿用原摇杆正负号逻辑。
5. 移到第2点，松开平面摇杆后按I；依次记录到第5点。五点满后再I只提示，不会覆盖。锁高启用初期未回中、或平面摇杆仍被推动时，I会拒绝，避免移动中误记点。
6. 按D，自动退出锁高，先检查整条轨迹，再按原接近/落笔/绘图/收笔流程执行。五点直线、五点曲线仍不连接首尾。
7. 不绘图而要恢复原摇杆时，先松开摇杆再发J。F、D、Q、M、其他运动/录制指令以及成功解析的角度命令都会退出锁高；I/P/H/L保持锁高。原8键板不用改程序；J默认从电脑串口发送。

注意：锁高示教保持纸面模型Z，并不在移动时自动抬笔。若笔已接触纸面，示教移动也可能留下笔迹；先在废纸上测试，不能把J当作自动离纸示教。退出后原后臂摇杆才恢复作用。

### 14.3 数据、速度和拒绝策略

- `planeTeachToggle()`：验证启动条件，保存首点FK坐标为 `planeTeachTarget`，保存当前三关节及夹爪指令作为一致性参考；启动不发运动指令。
- `planeTeachCtrl()`：只改变目标X/Y，Z始终不变；单步长度0.5mm，同时推动两轴时乘1/√2，使对角步长仍为0.5mm。保存浮点目标而不是每一步对取整角做FK，避免累积坐标漂移。
- 每步调用原任务五逆解，保留奇异余量、关节限位、相邻角度变化不超过3度的检查。成功后同一轮更新三个舵机，夹爪保持不变。间隔为 `max(35ms, 最大角差×DSD)`，外层仍受原摇杆DSD调度约束；H/L可调慢快，不是闭环恒速。
- 失败不更新目标或舵机，不会把越界移动累积成后续突跳；持续推同方向只报一次错误，松杆或成功移动后重置提示。反向移动仍可尝试离开边界。
- `teachPoint` 继续保存原始指令角。锁高期间另外用 `teachPlanePoint` 与 `teachPlaneMask` 保存本次浮点XY目标；日志同时列原始FK高度和保存的锁高目标。新一组首点验证通过后才清除旧缓存标记；失败会保留旧组。
- `drawStart()` 仍先检查原始姿态分支及5mm高度差，再使用锁高缓存XY、首点Z重新验证绘图点及每个路径采样。普通示教点没有缓存标记，沿用原来的FK-投影逻辑。缓存不绕过限位。
- 控制期间发现指令姿态或夹爪变化、进入其他任务或录制，会退出锁高。普通情况下不开J，`joyCtrl()`及任务一至三保持原逻辑。

### 14.4 为什么锁高后仍可能无法执行

J解决“手动独立调两个臂角难以维持高度”，不解决所有工作空间问题。点之间的弦线可能需要后臂低于10度，曲线可能越出示教点范围，或抬笔路径不可达；这些仍必须拒绝。尤其不要把全部点贴着r=10下限布置。新功能只保持计算模型高度，剩余几何标定误差、整数角量化和机械回差仍可能造成实物悬笔/压笔，不能通过取消限位或放宽5mm门槛解决。失败时应保留完整串口信息，区分“锁高移动受限”“统一高度后不可达”“绘图段/采样失败”或“接近/收笔路径失败”再处理。


## 十五 “统一高度后不可达”的定位与记录前校验

此错误不等于原来的示教角度越界，而是保持该点XY、改成首点Z后，新算出的角度超出了配置范围。少于5mm的高度差也可能触发：5mm只限制允许的高度修正量，不保证修正后的点可达。

以用户之前的纸面姿态作模型复现：f=113/r=10对应Z约59.856mm，f=108/r=10对应Z约62.300mm，两点原始逆解均可还原；把后者XY保留、Z改为59.856mm，要求r约6.503度，低于10度下限。此数值来自现有模型计算，不是对本次实际第2点的新测量。用户反馈这些姿态实际均接触纸面，因此也表明模型/零位/安装或测量存在剩余不一致，不能据此断言真实机构无法在纸上到达该点，更不能未经确认把下限改为0度。

### 本次行为改变

- `validateTeachProjection()` 由I记录和D启动共同调用，使用一致的首点Z、5mm上限和IK限位判断。I先验证原始FK→IK分支，再检查投影。D仍保留逐点及整条轨迹/抬笔检查。
- 记录失败会明确输出“未记录，点号不变”；不增计数、不清旧组、不改缓存、不下发运动。第2点不合格时调整后再I仍是第2点。满5点后尝试新首点也只有成功才替换原组。
- 限位错误由 `reportLimitAngle()` 打印越界关节名、未取整的要求角和该关节配置范围。例如本复现中为r约6.503、允许[10,170]度。不会把角度夹到10度冒充成功，也没有自动改变XY或纸面Z。
- 记录首点后提示立即J启用锁高摇杆；没有发J时仍是原独立关节控制，D时投影不代表示教移动时已锁高。
- 新增串口E：仅在五点模式且非自动流程/非录制时，关闭锁高并清空任务五示教计数及缓存标记，保持原位，不抬笔、不回中、不清任务二取放标定或任务三录制。固定图形、绘制/暂停和自动流程中拒绝。方便部分点记录失败后重新选首点，不必强行补满5点。

### 推荐排查顺序

上传新版后，五点模式下需要重教时先E；手动轻触纸面选一个不贴关节限位的起点，I成功后立即J，摇杆全部回中，再以XY模式定位其余点。每个点松开平面摇杆后I，确认“已记录”而非仅看到候选坐标。遇到移动受限则停止该方向或反向离开边界，不要取消保护。

J只能降低独立调关节造成的高度误差，不能修复几何标定或保证整段路径可达；实际发生压纸/离纸时应停下。若仍失败，保留首点及失败点的b/f/r、原始Z、首点Z、要求角度和错误位置，并确认是否显示“锁高示教已开”。如所有点实际贴纸但模型高度差明显，应重新核对同一次笔安装的纸面数据，再调整标定，而不是继续放宽高度修正或舵机限位。
